# Окупаемость высшего образования: Россия, Китай, ЮАР

Код и данные к работе «Окупаемость инвестиций в образование на примере России, Китая и ЮАР»
(Панфилова А.П., Калюжина С.О., Журавлева С.В., Брюзгина К.М.; МГУ имени М.В. Ломоносова, факультет ВМК, 2026).

Модель оценивает NPV, IRR и срок окупаемости высшего образования для поступающих в 2026 г.
Три страны описываются одной моделью жизненного цикла и различаются только значениями параметров.

## Что внутри

| Файл | Назначение |
|---|---|
| `lifecycle3.py` | ядро: денежные потоки жизненного цикла, профиль Минсера, прогрессивные налоги, безработица, отчисление; NPV, IRR, сроки окупаемости |
| `model_v3.py` | эконометрика и Монте-Карло: тесты ADF/KPSS и Чоу, ARIMA для роста ВВП, сравнение случайного блуждания и модели по закону Оукена для безработицы на скользящей проверке, регрессия премии на охват, 10 000 симуляций |
| `bridge3.py` | пошаговый переход от статического срока окупаемости к полной модели |
| `robust3.py` | устойчивость: замена прогнозов прогнозами МВФ, чувствительность к параметрам |
| `policy3.py` | длительность программы 4–6 лет, критическая плата за обучение |
| `hetero3.py` | направления подготовки, престиж вуза, разложение выгоды на зарплату и занятость |
| `unify3.py` | единая модель в относительных единицах и разложение Шепли разницы IRR между странами |
| `build_xlsx3.py` | Excel-файл для независимой сверки расчётов формулами |
| `figures_v4.py`, `slides_charts.py` | рисунки для статьи и презентации |
| `data/` | исходные ряды: макропоказатели, валовой охват, оценки премии |

## Запуск

```bash
pip install -r requirements.txt
python model_v3.py        # основной расчёт, результаты в out_v3/
python bridge3.py
python robust3.py
python policy3.py
python hetero3.py
python unify3.py
python build_xlsx3.py     # out_v3/Сверка_расчётов_окупаемость_v3.xlsx
python figures_v4.py      # figures_v4/
```

Случайное зерно фиксировано (2026), поэтому повторный запуск даёт те же числа.
Скрипты после `model_v3.py` читают его результаты из `out_v3/`.
